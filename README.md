Upload these files to your GitHub repository:
- aeje-challenge.css
- aeje-challenge.js

Recommended jsDelivr URLs:

CSS:
https://cdn.jsdelivr.net/gh/YOUR-USERNAME/YOUR-REPO@main/aeje-challenge.css

JS:
https://cdn.jsdelivr.net/gh/YOUR-USERNAME/YOUR-REPO@main/aeje-challenge.js
